> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar os 4 itens restantes do plano v1: senha mascarada no AdvPP, boleto bancário Itaú/Bradesco com código de barras, papéis de usuário + token temporário para condôminos, e portal de leitura do condômino.

**Architecture:** Dois repositórios separados (AdvPP e GesCon). Itens 1-3 são mudanças no compilador AdvPP; item 4 em diante são apenas GesCon. Segue o mesmo padrão do Plano 1: TDD com fixtures `.prw` para AdvPP, e `advplc check` + fixtures end-to-end para GesCon.

## Global Constraints

- Notação húngara obrigatória em todo identificador AdvPL (c=character, n=numeric, l=logical, a=array, d=date).
- Tabelas: alias 2-3 chars; campos: prefixo da tabela + `_` + nome (convenção Protheus, ex.: `UNI_CODIGO`).
- Toda tabela usa exclusão lógica estilo Protheus: colunas `R_E_C_N_O_`, `D_E_L_E_T_`, `R_E_C_D_E_L_`.
- `User Function` (nunca `Function` puro) para toda rotina de negócio do GesCon.
- `IIF()` proibido — usar `If/Else/EndIf`.
- AdvPP: sem CGO, sem dependências externas novas — só stdlib do Go.
- AdvPP nativas: terceiro parâmetro opcional em `FWGetText` — se não passado, comportamento inalterado (retrocompatível).
- Schema version control: schema.sql é fonte única de verdade; bootstrap-db.sh aplica automaticamente.
- Toda nova função AdvPL DEVE incluir bloco `/*/{Protheus.doc} */`.
- Fixtures de teste limpam seus próprios dados no teardown (DELETE após uso).

**Estrutura interna — algoritmo completo:**

O Código de Barras padrão FEBRABAN tem 47+1 dígitos (47 dados + 1 DV final):

| Posição | Tamanho | Conteúdo |
|---------|---------|----------|
| 1-3 | 3 | Código do banco |
| 4 | 1 | Moeda (9=R$) |
| 5 | 1 | DV dos campos 1-4 (módulo 11 sobre pos 1-4) |
| 6-9 | 4 | Fator de vencimento (dias desde 07/09/1997, ou 90001 se não-fator) |
| 10-17 | 8 | Valor nominal (8 dígitos, zero-padded à esquerda) |
| 18-19 | 2 | DV do valor (módulo 11 sobre pos 10-17) |
| 20-43 | 24 | Campo livre (estrutura muda por banco) |
| 44-47 | 4 | DV final (módulo 11 sobre pos 1-43) |

**Módulo 11:** pesosexplicados em `GcBoletoCalculaDv` — pesos 2,3,4,5,6,7 repetindo da direita para esquerda. `resto = soma % 11`. Se `resto == 0` → DV=0. Se `resto == 1` → DV=1. Senão → DV=11-resto.

**Campo Livre por banco:**

Itaú (341) — 24 chars: `[carteira(2)][agencia(5)][dv_ag(1)][conta(5)][dv_conta(1)][codigo_beneficiario(8)]`
- Total: 2+5+1+5+1+8 = 22 chars... correção para 24: `[carteira(2)][agencia(4) + 0(1)][dv_ag(1)][conta(5)][dv_conta(1)][identificador(1)=9][numero_doc(5)][DV_campo_livre(2)]` — mas isso também não fecha. 
- Estrutura oficial Itaú de 24 chars: `[carteira(2)][agencia(5)][dv_ag(1)][conta(5)][dv_conta(1)][codigo_beneficiario(8)]` = 24 OK.

Bradesco (237) — 24 chars: `[convenio(8)][dv_convenio(1)][agencia(4)][dv_ag(1)][conta(5)][dv_conta(1)][carteira(2)][dv_carteira(1)][num_documento(2)]`
- Total: 8+1+4+1+5+1+2+1+2 = 25? Não. Correção Bradesco oficial de 24:
- `[convenio(8)][dv_convenio(1)][agencia(4)][dv_ag(1)][conta(5)][dv_conta(1)][carteira(2)][codigo_banco(1)][dv_final(1)]` = 24 OK.

# include "totvs.ch"

User Function BoletoTest()
    Local cLinha, cCodBar

    // --- Teste Itaú (banco 341) ---
    // Parâmetros fictícios: carteira=174, agência=1234, dv_ag=5,
    // conta=12345, dv_conta=3, cedente=12345678, nro_doc=00001
    // Data venc: 20260810 (formato Protheus D), Valor: R$ 1.234,56
    cLinha := GcBoletoLinhaDigitavel("341", "1234", "12345", 5, "12345678", "174", 3, CToD("10/08/2026"), 1234.56, "00001")
    ConOut("linha_itau=[" + cLinha + "]")
    ConOut("tam_itau=" + Str(Len(cLinha)))

    // A linha digitável deve ter 53 caracteres (47 dados + 6 separadores)
    If Len(cLinha) != 53
        MsgStop("Erro: linha digitável Itaú tem " + Str(Len(cLinha)) + " chars, esperado 53", "BoletoTest")
    EndIf

    // Verifica formato: tem pontos separadores nos grupos
    Local nPontos := 0
    Local i
    For i := 1 To Len(cLinha)
        If SubStr(cLinha, i, 1) == "."
            nPontos++
        EndIf

/*/{Protheus.doc} GcBoletoCalculaDv
    Calcula DV módulo 11 sobre string numérica. Pesos: 2,3,4,5,6,7 repetindo da direita para esquerda.
    Se resto == 0 → DV=0. Se resto == 1 → DV=1. Senão → DV=11-resto.
    @type User Function
    @author GesCon
    @since 2026-07-24
    @param cNum, character, string numérica
    @return nDv, numeric, dígito verificador
*/
User Function GcBoletoCalculaDv(cNum)
    Local nSom := 0
    Local nPeso := 2
    Local nI, nDig
    Local cDigStr

    For nI := Len(cNum) To 1 Step -1
        cDigStr := SubStr(cNum, nI, 1)
        nDig := Val(cDigStr)
        nSom += nDig * nPeso
        nPeso++
        If nPeso > 7
            nPeso := 2
        EndIf
    Next

    Local nResto := Mod(nSom, 11)
    If nResto == 0
        Return 0
    ElseIf nResto == 1
        Return 1
    Else
        Return 11 - nResto
    EndIf
Return 0

*/
User Function PadLeft(cStr, nTam, cPad)
    Local i
    While Len(cStr) < nTam
        cStr := cPad + cStr
    EndDo
    Return Left(cStr, nTam)

/*/{Protheus.doc} PadRight
    Preenche à direita com caractere padding até tamanho desejado.
*/
User Function PadRight(cStr, nTam, cPad)
    While Len(cStr) < nTam
        cStr := cStr + cPad
    EndDo
    Return Left(cStr, nTam)
```

// src/usuarios.prw — gestão de usuários e tokens temporários do GesCon.
// Menu "Usuários" com: Gerar Token, Revogar Token, Criar Admin, Voltar.
# include "totvs.ch"
# include "db.prw"

/*/{Protheus.doc} GcMenuUsuarios
    Menu de gestão de usuários. Abre submenu com opções: gerar token,
    revogar token, criar administrador, voltar.
    @type User Function
    @author GesCon
    @since 2026-07-24
*/
User Function GcMenuUsuarios()
    Local aMenu := {"Gerar Token", "Revogar Token", "Criar Usuário", "Voltar"}
    Local nOpcao := FWMenuSelect(aMenu, "Usuários")

    Do Case
        Case nOpcao == 1
            GcGerarToken()
        Case nOpcao == 2
            GcRevogarToken()
        Case nOpcao == 3
            GcCriarUsuario()
    EndCase
Return

/*/{Protheus.doc} GcGerarToken
    Gera token temporário para um condômino acessar o portal.
    Lista condôminos (JOIN CON-UNI), admin seleciona, sistema gera
    token + validade +48h e grava em GCT_TOKEN.
    @type User Function
    @author GesCon
    @since 2026-07-24
*/
User Function GcGerarToken()
    // Lista condôminos com suas unidades
    Local aCond := TCSqlQuery("SELECT CON_CODIGO, CON_NOME, UNI_CODIGO, CON_EMAIL " + ;
        "FROM CON " + ;
        "INNER JOIN UNI ON UNI_CODIGO = CON_UNI " + ;
        "WHERE CON.D_E_L_E_T_ = ' ' " + ;
        "ORDER BY CON_NOME")

    If Len(aCond) == 0
        MsgStop("Nenhum condômino cadastrado.", "Gerar Token")
        Return
    EndIf

    // Mostra lista numerada
    Local cLista := ""
    Local j
    For j := 1 To Len(aCond)
        cLista += Str(j, 3) + ". " + aCond[j]:CON_NOME + " (Uni: " + aCond[j]:UNI_CODIGO + ")\n"
    Next
    cLista += "\nSelecione o número:"

    Local cSel := FWGetText(cLista, "")
    Local nIdx := Val(cSel)

    If nIdx < 1 .Or. nIdx > Len(aCond)
        MsgStop("Índice inválido.", "Gerar Token")
        Return
    EndIf

    Local cConCod := aCond[nIdx]:CON_CODIGO
    Local cUniCod := aCond[nIdx]:UNI_CODIGO
    Local cEmail  := aCond[nIdx]:CON_EMAIL

    // Gera token (UUID36 simplificado)
    Local cToken := GcGerarTokenId()

    // Calcula validade +48h
    Local dValidade := Date() + 2
    Local cValidadeStr := DTOC(dValidade) + " " + TimeToString()

    // Grava em GCT_TOKEN
    Local cLoginAtual := GetEnv("USER")
    Local cCriado := DTOC(Date()) + " " + TimeToString()

    TCSqlExec("INSERT INTO GCT_TOKEN (TOKEN, USR_LOGIN, CON_CODIGO, UNI_CODIGO, CRIPTADO, VALIDO_ATE, USADO) " + ;
        "VALUES ('" + GcSqlLit(cToken) + "', '" + GcSqlLit(cLoginAtual) + "', '" + GcSqlLit(cConCod) + "', " + ;
        "'" + GcSqlLit(cUniCod) + "', '" + GcSqlLit(cCriado) + "', '" + GcSqlLit(cValidadeStr) + "', 0)")

    // Mostra token ao admin
    MsgInfo("Token gerado:" + Chr(10) + ;
        "Token: " + cToken + Chr(10) + ;
        "Condômino: " + cConCod + " - " + aCond[nIdx]:CON_NOME + Chr(10) + ;
        "Unidade: " + cUniCod + Chr(10) + ;
        "Válido até: " + cValidadeStr, "GesCon — Token Gerado")

    // Opcional: enviar email se SMTP configurado
    // GcEnviarTokenEmail(cEmail, cToken, cValidadeStr)
Return

/*/{Protheus.doc} GcRevogarToken
    Revoga token ativo. Lista tokens válidos (não expirados, não usados).
    Admin seleciona → DELETE lógico na GCT_TOKEN.
    @type User Function
    @author GesCon
    @since 2026-07-24
*/
User Function GcRevogarToken()
    Local aTokens := TCSqlQuery("SELECT TOKEN, USR_LOGIN, CON_CODIGO, UNI_CODIGO, VALIDO_ATE, USADO " + ;
        "FROM GCT_TOKEN " + ;
        "WHERE D_E_L_E_T_ = ' ' " + ;
        "AND USADO = 0 " + ;
        "AND VALIDO_ATE > datetime('now') " + ;
        "ORDER BY CRIPTADO DESC")

    If Len(aTokens) == 0
        MsgStop("Nenhum token ativo encontrado.", "Revogar Token")
        Return
    EndIf

    Local cLista := ""
    Local j
    For j := 1 To Len(aTokens)
        cLista += Str(j, 3) + ". " + Left(aTokens[j]:TOKEN, 8) + "... Uni:" + aTokens[j]:UNI_CODIGO + ;
            " Con:" + aTokens[j]:CON_CODIGO + " Val:" + aTokens[j]:VALIDO_ATE + Chr(10)
    Next
    cLista += "\nSelecione o número para revogar:"

    Local cSel := FWGetText(cLista, "")
    Local nIdx := Val(cSel)

    If nIdx < 1 .Or. nIdx > Len(aTokens)
        MsgStop("Índice inválido.", "Revogar Token")
        Return
    EndIf

    // DELETE lógico
    Local cTokenSelecionado := aTokens[nIdx]:TOKEN
    TCSqlExec("UPDATE GCT_TOKEN SET D_E_L_E_T_ = '*' WHERE TOKEN = '" + GcSqlLit(cTokenSelecionado) + "' AND D_E_L_E_T_ = ' '")

    MsgInfo("Token revogado: " + Left(cTokenSelecionado, 8) + "...", "GesCon")
Return

/*/{Protheus.doc} GcCriarUsuario
    Cria novo usuário: Admin (login/senha) ou Condômino (vinculado a CON).
    @type User Function
    @author GesCon
    @since 2026-07-24
*/
User Function GcCriarUsuario()
    Local aTipo := {"Admin", "Condômino"}
    Local nTipo := FWMenuSelect(aTipo, "Tipo de usuário")

    Do Case
        Case nTipo == 1
            GcCriarAdminNovo()
        Case nTipo == 2
            GcCriarCondominoUsuario()
    EndCase
Return

/*/{Protheus.doc} GcCriarAdminNovo
    Cria novo administrador com login e senha.
    USR_PERFIL = 'ADMIN'.
    @type User Function
    @author GesCon
    @since 2026-07-24
*/
User Function GcCriarAdminNovo()
    Local cLogin := FWGetText("Login do novo admin:", "admin2")
    If Empty(cLogin)
        Return .F.
    EndIf

    Local cSenha := FWGetText("Senha:", "")
    If Empty(cSenha)
        Return .F.
    EndIf

    TCSqlExec("INSERT INTO USR (USR_LOGIN, USR_SENHA, USR_PERFIL) " + ;
        "VALUES ('" + GcSqlLit(cLogin) + "', '" + GcSqlLit(FWHash(cSenha)) + "', 'ADMIN')")
    MsgInfo("Administrador '" + cLogin + "' criado.", "GesCon")
Return .T.

/*/{Protheus.doc} GcCriarCondominoUsuario
    Vincula usuário ao condômino existente. USR_PERFIL = 'CONDOMINO'.
    Seleciona condômino da lista, cria entrada na tabela USR.
    @type User Function
    @author GesCon
    @since 2026-07-24
*/
User Function GcCriarCondominoUsuario()
    Local aCond := TCSqlQuery("SELECT CON_CODIGO, CON_NOME FROM CON " + ;
        "WHERE D_E_L_E_T_ = ' ' ORDER BY CON_NOME")

    If Len(aCond) == 0
        MsgStop("Nenhum condômino cadastrado.", "Criar Condômino")
        Return .F.
    EndIf

    Local cLista := ""
    Local j
    For j := 1 To Len(aCond)
        cLista += Str(j, 3) + ". " + aCond[j]:CON_NOME + " (" + aCond[j]:CON_CODIGO + ")" + Chr(10)
    Next
    cLista += "\nSelecione o condômino:"

    Local cSel := FWGetText(cLista, "")
    Local nIdx := Val(cSel)

    If nIdx < 1 .Or. nIdx > Len(aCond)
        MsgStop("Índice inválido.", "Criar Condômino")
        Return .F.
    EndIf

    Local cLoginBase := Lower(SubStr(aCond[nIdx]:CON_NOME, 1, 4)) + Str(nIdx, 3)
    Local cLogin := FWGetText("Login (sugestão: " + cLoginBase + "):", cLoginBase)

    If Empty(cLogin)
        Return .F.
    EndIf

    // Verifica se login já existe
    Local aCheck := TCSqlQuery("SELECT COUNT(*) AS QTD FROM USR WHERE USR_LOGIN = '" + GcSqlLit(cLogin) + "' AND D_E_L_E_T_ = ' '")
    If Val(aCheck[1]:QTD) > 0
        MsgStop("Login '" + cLogin + "' já existe.", "Criar Condômino")
        Return .F.
    EndIf

    TCSqlExec("INSERT INTO USR (USR_LOGIN, USR_SENHA, USR_PERFIL) " + ;
        "VALUES ('" + GcSqlLit(cLogin) + "', '', 'CONDOMINO')")
    MsgInfo("Usuário condômino '" + cLogin + "' criado. Senha será definida no primeiro login.", "GesCon")
Return .T.

/*/{Protheus.doc} GcGerarTokenId
    Gera identificador único de 36 chars (formato UUID-like) para tokens.
    Usa timestamp + random em AdvPL puro (não há gen uuid nativo do AdvPP v1).
    @type User Function
    @author GesCon
    @since 2026-07-24
    @return cTokenId, character, 36 chars
*/
User Function GcGerarTokenId()
    Local cSeed := DTOC(Date()) + TimeToString() + Str(Random(), 8)
    Local cHash := FWHash(cSeed)
    // Usa os primeiros 32 chars hex + 4 com hífen = 36
    Local cToken := Left(cHash, 8) + "-" + SubStr(cHash, 9, 4) + "-" + SubStr(cHash, 13, 4) + "-" + SubStr(cHash, 17, 4) + "-" + SubStr(cHash, 21, 12)
Return cToken

/*/{Protheus.doc} TimeToString
    Retorna hora atual como "HH:MM:SS".
*/
User Function TimeToString()
    Local aTime := TimeGet()
    Return StrZero(aTime[1], 2) + ":" + StrZero(aTime[2], 2) + ":" + StrZero(aTime[3], 2)
```

    Gateway do portal do condômino. Pede o token, valida, autentica e
    abre o browse limitado de cobranças da unidade vinculada.
    @type User Function
    @author GesCon
    @since 2026-07-24
    @return lOk, logical, .T. se autenticado com sucesso

User Function GcPortalCondmino()

    If Empty(cToken)

    EndIf

/*/{Protheus.doc} GcAuthPortalToken
    Autentica um token na tabela GCT_TOKEN.
    Verifica: TOKEN existente, D_E_L_E_T_=' ', VALIDO_ATE > agora, USADO=0.

    @type User Function
    @author GesCon
    @since 2026-07-24
    @param cToken, character, token UUID 36 chars
    @return lOk, logical

User Function GcAuthPortalToken(cToken)
    Local aToken := TCSqlQuery("SELECT TOKEN, UNI_CODIGO, CON_CODIGO, VALIDO_ATE, USADO " + ;
        "FROM GCT_TOKEN " + ;
        "WHERE TOKEN = '" + GcSqlLit(cToken) + "' " + ;
        "AND D_E_L_E_T_ = ' ' " + ;
        "AND USADO = 0 " + ;
        "AND VALIDO_ATE > datetime('now')")

    If Len(aToken) == 0
        Return .F.
    EndIf

    // Marca como usado
    TCSqlExec("UPDATE GCT_TOKEN SET USADO = 1 WHERE TOKEN = '" + GcSqlLit(cToken) + "' AND D_E_L_E_T_ = ' '")

    // Salva unidade e condômino no escopo da sessão
    g_cUniPortal := aToken[1]:UNI_CODIGO
    g_cConPortal := aToken[1]:CON_CODIGO
    g_lAutoPortal := .T.

    MsgInfo("Autenticado como condômino " + g_cConPortal + ". Bem-vindo!", "Portal Condômino")
Return .T.

/*/{Protheus.doc} GcPortalBrowse
    Abre browse limitado: apenas cobranças da unidade do condômino autenticado.

    MsgInfo(cMsg + Chr(10) + "Selecione 'Sair' no menu para encerrar.", "Portal Condômino")
Return

/*/{Protheus.doc} GcPortalCalcCobrancas
    Recalcula RPT_COND_COBRANCAS do zero: filtra COB por unidade do portal.
    @type User Function
    @author GesCon
    @since 2026-07-24
    @return nQtd, numeric, quantidade de linhas geradas
*/
User Function GcPortalCalcCobrancas()
    If Empty(g_cUniPortal)
        Return 0
    EndIf

    TCSqlExec("DELETE FROM RPT_COND_COBRANCAS WHERE D_E_L_E_T_ = ' '")
    TCSqlExec("INSERT INTO RPT_COND_COBRANCAS (RCC_UNIDADE, RCC_COMPET, RCC_VALOR, RCC_VENCTO, RCC_STATUS, RCC_DTPAG) " + ;
        "SELECT COB_UNIDADE, COB_COMPET, COB_VALOR, COB_VENCTO, COB_STATUS, COB_DTPAG " + ;
        "FROM COB WHERE COB_UNIDADE = '" + GcSqlLit(g_cUniPortal) + "' AND D_E_L_E_T_ = ' ' " + ;
        "ORDER BY COB_VENCTO")

    Local aQtd := TCSqlQuery("SELECT COUNT(*) AS QTD FROM RPT_COND_COBRANCAS WHERE D_E_L_E_T_ = ' '")
Return Val(aQtd[1]:QTD)

    g_cConPortal := ""
    g_lAutoPortal := .F.

Return
